# cpm Backport

This is a script to backport [cpm](https://github.com/skaji/cpm) to work on
perl versions older than 5.24.

*cpm* is widely used in CI systems when testing modules that are compatible
with older perl versions. These no longer work with the stable release of cpm,
as it requires perl version 5.24.

This script does a rudimentary syntax conversion of cpm so that it can run on
older perl versions. As it only attempts to convert syntax that is used in
cpm itself, it may break with future versions of cpm. It also currently
doesn't attempt to fix any syntax of dependencies, so if they become broken on
newer perl versions it will also break this script.

As an additional benefit, the *cpm* generated by this script includes Carton,
which allows *cpm* to read `cpanfile.snapshot` files without installing any
additional prerequisites.
